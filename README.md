# Apartment Strong

Website source for ApartmentStrong.com.

## Publishing
This repository is intended to be connected to Netlify. Production changes should be reviewed before publishing.

## Accuracy rule for Current Opportunities
- Check official utility/government/program sources first.
- Show a visible last-reviewed date.
- Do not label a program AVAILABLE unless the current official source supports that status.
- Keep paused/closed programs separate from current opportunities.
- Link owners directly to the official source.
