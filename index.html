Planning an Improvement for Your Apartment Property? Start Here.

Apartment Strong helps Sacramento-area apartment owners plan property improvements — from HVAC and electrical upgrades to EV charging, insulation, windows and other building projects.

Before you start, we check available incentives, financing options and related improvements that may make the project more practical.

Examples of What We Can Help With

Replacing old HVAC? We can check heat-pump options, electrical needs and available incentives.

Adding EV charging? We can review electrical capacity, charging options and available incentives.

Planning electrical, insulation or window improvements? We can look for related improvements or programs worth considering at the same time.

Already planning a larger project? We can help with planning, permitting, coordination and licensed construction where applicable.

If we find something useful, we'll show you. If we don't, we'll tell you. You decide what to do.

SMUD Multifamily Electrification

For qualifying multifamily properties. SMUD publishes incentives for measures including heat-pump HVAC, heat-pump water heating, electrical infrastructure and other improvements.

Official SMUD Program →
AVAILABLE NOW

EV Charging

SMUD's multifamily program includes qualifying EV charging measures and related electrical infrastructure. Project requirements should be checked before installation begins.

Official SMUD Program →
AVAILABLE WITH CONDITIONS

Insulation & Building Envelope

Building-envelope measures can qualify under specific program conditions. We check how these measures fit with the planned project rather than treating them as automatic standalone incentives.

Official SMUD Program →
FINANCING

GoGreen Business Financing

California's GoGreen Business program includes pathways for multifamily owners financing qualifying clean-energy and efficiency improvements. The former GoGreen Multifamily program was folded into GoGreen Business.

Official California Treasurer Source →
NEW CONSTRUCTION

SMUD All-Electric Smart Homes

SMUD publishes builder incentives for qualifying all-electric new multifamily homes and ADUs. This is separate from its existing-building retrofit program.
