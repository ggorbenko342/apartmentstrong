SMUD Multifamily Electrification

For qualifying multifamily properties with 5+ units. Current incentives include heat-pump HVAC, heat-pump water heating, electrical infrastructure and other measures.

SMUD currently lists incentives for qualifying low-power Level 2 charging and certain related electrical upgrades. EV-only participation can be possible.

Programs We Are Watching

Some California multifamily programs periodically pause, close reservations or exhaust funding. We keep these separate so owners do not waste time treating an unavailable program as current.

We will add direct official links and status notes when a program is relevant to Sacramento-area properties.

Planning an improvement? Check program requirements before construction starts. Some programs require application or approval before work begins.
